## 7. 追踪与评测

- **trace**：每次调用记录 thread_id、节点路径、每步 token 与成本、工具调用与结果摘要、耗时；敏感输入脱敏
- **评测集**：`app/evals/datasets/<suite>.jsonl`（正常 / 边界 / 对抗），每条含输入、期望（确定性断言或评分 rubric）
- **阈值与基线**：通过率 ≥ <x>%、平均成本 ≤ ¥<y>、P95 延迟 ≤ <z> 秒；基线日期与提交记录在下方
- **回归纪律**：改提示词/模型/工具必跑；低于基线不得合并；失败样例要写分析

## 8. 失败模式与兜底

| 失败模式 | 现象 | 兜底 |
|---|---|---|
| 无限循环 | 反复调用同一工具 | 最大步数 + 重复检测 + 终止返回 |
| 工具幻觉 | 调用不存在的工具/参数 | 白名单 + 参数校验 + 错误回灌给模型 |
| 上下文爆炸 | token 飙升、变慢变贵 | 摘要/裁剪 + 硬上限 |
| 非确定性 | 测试时好时坏 | 单测用假模型；评测用阈值而非逐字比对 |
| 副作用重复 | 重复下单/重复发消息 | 幂等键 + 人工确认 |
