## ADR-0001 <示例：服务端渲染选型>

- 日期：YYYY-MM-DD
- 状态：已采纳
- 背景：需要在无重型前端工程的前提下做局部刷新与组件复用。
- 决策：服务端用 HTMX + pyjoist 组件化；富交互页面才引入 React。
- 被否方案：全量 SPA（成本过高、SEO 与首屏差）；纯 Jinja 宏（缺少类型化数据契约）。
- 影响：所有 UI 片段都要落成组件 + 模板，路由只做 load/build/render。
- 回滚方式：保留 JSON 接口，前端可平滑替换渲染层。
